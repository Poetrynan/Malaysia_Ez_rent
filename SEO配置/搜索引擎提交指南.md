# 搜索引擎提交指南

## 一、Google Search Console

### 步骤 1：访问并登录

1. 访问 https://search.google.com/search-console
2. 使用 Google 账号登录

### 步骤 2：添加网站

1. 点击 "添加属性"
2. 选择 "网址前缀"
3. 输入 `https://ezrent.my`
4. 点击 "继续"

### 步骤 3：验证所有权

**推荐方法：HTML 标签**

1. 选择 "HTML 标签"
2. 复制验证码（如 `abc123xyz`）
3. 在 `layout.tsx` 的 `metadata.verification.google` 中填入
4. 部署网站
5. 回到 Search Console 点击 "验证"

### 步骤 4：提交 Sitemap

1. 左侧菜单 → "站点地图"
2. 输入 `sitemap.xml`
3. 点击 "提交"

### 步骤 5：请求索引

1. 顶部搜索框输入首页 URL
2. 点击 "请求编入索引"
3. 等待处理（通常几小时到几天）

## 二、百度站长平台

### 步骤 1：访问并注册

1. 访问 https://ziyuan.baidu.com
2. 注册百度账号并登录

### 步骤 2：添加网站

1. 点击 "添加网站"
2. 输入 `https://ezrent.my`
3. 选择 "HTML 标签验证"

### 步骤 3：验证所有权

1. 复制百度提供的验证码
2. 在 `layout.tsx` 的 `metadata.verification.baidu` 中填入（如需要）
3. 部署网站
4. 回到百度站长平台点击 "验证"

### 步骤 4：提交 Sitemap

1. 左侧菜单 → "数据引用" → "站点地图"
2. 点击 "添加新数据"
3. 输入 sitemap URL
4. 点击 "提交"

### 步骤 5：推送 URL

百度支持主动推送，可以加速收录：

```bash
# 使用 curl 推送
curl -H 'Content-Type: text/plain' --data-binary @urls.txt \
  "http://data.zz.baidu.com/urls?site=ezrent.my&token=YOUR_TOKEN"
```

## 六、常见问题

### Q：提交后多久能被收录？

A：通常 1-7 天，百度可能需要更长时间（1-4 周）

### Q：为什么页面没被索引？

A：检查 robots.txt 是否阻止了爬虫，检查页面是否有 meta noindex 标签

### Q：如何查看收录状态？

A：在 Search Console → "页面" 中查看已索引和未索引的页面
