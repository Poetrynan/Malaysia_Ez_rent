# 部署指南

## 前置条件

| 工具 | 版本 | 用途 |
|------|------|------|
| Node.js | 18+ | 前端运行 |
| Python | 3.11+ | 后端运行 |
| Git | - | 版本控制 |
| Supabase账号 | - | 数据库服务 |
| Vercel账号 | - | 前端部署 |
| Render账号 | - | 后端部署 |

## 第一步：Supabase 数据库

### 1.1 创建项目

1. 登录 [supabase.com](https://supabase.com)
2. 点击 "New Project"
3. 填写项目名称和数据库密码
4. 选择区域（建议 Singapore）

### 1.2 导入数据库

在 Supabase 控制台的 SQL Editor 中：

1. 先运行 `schema.sql` 创建所有表
2. 按顺序运行 `migrations/*.sql` 文件（001-033）

```sql
-- 示例：运行 schema.sql
-- 复制粘贴整个文件内容到 SQL Editor，点击 Run
```

### 1.3 配置 Storage

1. 进入 Storage 页面
2. 创建 Bucket: `unit-media`
3. 设置 Policy 允许 authenticated 用户上传

### 1.4 获取 API Keys

在 Settings > API 中获取：
- `URL`: https://xxx.supabase.co
- `anon public` key
- `service_role` key

## 第二步：后端部署（Render）

### 2.1 准备代码

确保 `backend/` 目录下有：
- `requirements.txt`
- `run.py` 或 `main.py`

### 2.2 创建 Render 服务

1. 登录 [render.com](https://render.com)
2. 点击 "New" > "Web Service"
3. 连接 GitHub 仓库
4. 配置：
   - **Name**: ezrent-api
   - **Runtime**: Python
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python run.py`
   - **Port**: 8000

### 2.3 配置环境变量

在 Environment 中添加：

```env
SUPABASE_URL=https://xxx.supabase.co
SUPABASE_ANON_KEY=xxx
SUPABASE_SERVICE_ROLE_KEY=xxx
GEMINI_API_KEY=xxx
GOOGLE_MAPS_API_KEY=xxx
TAVILY_API_KEY=xxx
FRONTEND_URL=https://ezrent.vercel.app
EXTRA_ORIGINS=http://localhost:3000
```

---

## 第三步：前端部署（Vercel）

### 3.1 准备代码

确保 `frontend/` 目录下有：
- `package.json`
- `next.config.ts`

### 3.2 创建 Vercel 项目

1. 登录 [vercel.com](https://vercel.com)
2. 点击 "New Project"
3. 导入 GitHub 仓库
4. 选择 `frontend` 目录作为 Root Directory

### 3.3 配置环境变量

在 Settings > Environment Variables 中添加：

```env
NEXT_PUBLIC_SUPABASE_URL=https://xxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=xxx
NEXT_PUBLIC_AGENT_API_URL=https://ezrent-api.onrender.com/api/chat
NEXT_PUBLIC_AGENT_MODEL=gemini-2.0-flash
NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=xxx
```

### 3.4 部署

点击 "Deploy" 等待构建完成。

## 第四步：域名配置（可选）

### 4.1 Vercel 域名

1. 在 Vercel Settings > Domains
2. 添加你的域名（如 `ezrent.my`）
3. 按提示配置 DNS

### 4.2 Render 域名

1. 在 Render Settings > Custom Domains
2. 添加 API 域名（如 `api.ezrent.my`）

## 常见问题

### Q: 部署后页面空白？
A: 检查环境变量是否正确配置，特别是 `NEXT_PUBLIC_` 前缀的变量。

### Q: AI 对话无响应？
A: 检查后端是否正常运行，环境变量 `GEMINI_API_KEY` 是否有效。

### Q: 数据库连接失败？
A: 检查 Supabase URL 和 Key 是否正确，是否有网络访问限制。

### Q: 图片上传失败？
A: 检查 Supabase Storage Bucket 是否创建，RLS Policy 是否配置。

## 本地开发

### 启动后端

```bash
cd backend
pip install -r requirements.txt
python run.py
```

### 启动前端

```bash
cd frontend
npm install
npm run dev
```

或使用 `start.bat` 一键启动（Windows）。
