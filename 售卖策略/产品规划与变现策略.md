> 最后更新：2026-06-02

## 一、产品定位

### 当前定位

**Malaysia Ez Rent** 是面向马来西亚国际租客的智能租房平台，集成 AI 助手、全流程租约管理、手机扫码缴租、多中介独立挂牌等功能。

### 目标用户

| 用户类型 | 数量 | 特点 |
|---------|------|------|
| 国际租客 | 130,000+ | 留学生、外派员工、外籍人士 |
| 中介 | 500+ | 房产中介公司 |
| 房东 | 1000+ | 房产所有者 |

### 竞争优势

| 优势 | 说明 |
|------|------|
| AI 智能助手 | 通勤测算、汇率换算、语义搜索 |
| 全流程管理 | 房源→租约→支付→报修 |
| 多中介支持 | 数据隔离，独立管理 |
| 中英双语 | 满足国际租客需求 |
| 手机友好 | 扫码缴租、匿名上传 |

## 五、数据护城河

### 小区知识库

#### 目标

为平台创建马来西亚全境的小区/公寓知识库，用于 AI 智能推荐系统。

#### 数据来源

| 来源 | 说明 |
|------|------|
| Google Maps | 地址、坐标、照片、评分 |
| 小红书/微信公众号 | 中国留学生真实评价 |
| Google Reviews | 英文评价 |
| 中介咨询 | 最准确的租金和设施信息 |

#### 采集范围

```
马来西亚所有大学
    ↓
每所大学周边 3-5 公里范围
    ↓
所有住宅小区/公寓
```

#### 数据字段

```json
{
  "university_name": "Sunway University",
  "community_name": "Sunway Residence",
  "address": "Jalan Taylor's, 47500 Subang Jaya",
  "latitude": 3.0733,
  "longitude": 101.6067,
  "description": "位于双威城核心地段的高端公寓...",
  "property_type": "Condominium",
  "price_range": {"min": 800, "max": 2500, "currency": "MYR"},
  "pros": ["交通便利", "生活配套齐全"],
  "cons": ["租金偏高"],
  "facilities": ["Swimming Pool", "Gymnasium", "24-Hour Security"]
}
```

#### 数据量目标

| 类别 | 目标数量 |
|------|---------|
| 大学 | 30+ 所 |
| 小区 | 每所大学 5-15 个 |
| **总计** | **200-400 个小区** |

#### 价值

```
别人能抄走的：
├── 代码 → 开源就能复制
├── 功能 → 竞品也能做
└── UI → 设计能模仿

别人抄不走的：
├── 小区知识库 → 您积累的数据
├── 房源数据 → 中介上传的
├── 用户数据 → 租客使用的
└── AI 模型 → 基于数据训练的
```

## 八、风险与应对

### 市场风险

| 风险 | 应对 |
|------|------|
| 大平台进入 | 深耕细分市场 |
| 用户增长慢 | 加大推广力度 |
| 中介流失 | 提高服务质量 |

### 技术风险

| 风险 | 应对 |
|------|------|
| 支付安全 | 使用 Stripe 等成熟方案 |
| 数据泄露 | RLS + 加密 |
| 服务不稳定 | 多地部署 |

### 财务风险

| 风险 | 应对 |
|------|------|
| 现金流不足 | 控制成本 |
| 收入不及预期 | 调整定价 |
| 融资困难 | 保持盈利 |
