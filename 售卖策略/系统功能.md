# 系统功能清单

## 项目定位

马来西亚留学生智能租房平台，面向国际留学生（尤其中国留学生）提供一站式租房服务。

---

## 核心功能模块

### 1. 房源管理

| 功能 | 描述 |
|------|------|
| 房源发布 | 中介可发布房源，支持图片、视频、描述 |
| 房型管理 | Studio / Master Room / Medium Room / Small Room / Ensuite / Whole Unit |
| 小区管理 | 关联小区信息、设施、GPS坐标 |
| 状态管理 | available / rented / maintenance |
| AI语义搜索 | 基于pgvector的房源智能匹配 |
| 房源复制 | 快速复制已有房源信息 |

### 2. 租约管理

| 功能 | 描述 |
|------|------|
| 租约创建 | 中介为租客创建租约合同 |
| 自动生成账单 | 根据租期自动生成月度付款记录 |
| 租约状态 | active / expired / terminated / completed |
| 租约终止 | 租客可主动终止租约 |
| 合租支持 | lease_groups 支持多人合租 |
| 租约转移 | 租客替换功能（substitute_co_tenant） |

### 3. 支付系统

| 功能 | 描述 |
|------|------|
| 自动账单生成 | 创建租约时自动按月生成付款记录 |
| 手机扫码缴租 | 扫QR码进入匿名上传页面 |
| 收款码分离 | 首月→中介收款码，后续→房东收款码 |
| 支付凭证审核 | 中介审核租客上传的转账截图 |
| 实时状态更新 | Supabase Realtime 实时推送 |
| 付款记录导出 | 历史收租核查表 |

### 4. 中介管理

| 功能 | 描述 |
|------|------|
| 中介注册 | REN牌照验证，公司信息登记 |
| 资质审核 | 管理员审核中介资质 |
| 数据隔离 | 中介只能看到自己的房源 |
| 个人主页 | 中介展示页面（牌照、经验、专长） |
| 收款码管理 | 每个中介独立的收款码 |

### 5. AI 智能助手

| 功能 | 描述 |
|------|------|
| 通勤测算 | 任意两地址间的通勤时间（驾车/公交/步行） |
| 汇率换算 | MYR/CNY/USD等实时汇率 |
| 假期查询 | 马来西亚公众假期 |
| 网页搜索 | 实时搜索留学生活信息 |
| 语义搜索 | 基于向量的房源智能匹配 |

### 6. 报修系统

| 功能 | 描述 |
|------|------|
| 工单提交 | 租客提交报修请求 |
| 分类管理 | 空调/水电/家具/电器/其他 |
| 对话功能 | 中介与租客在线沟通 |
| 状态跟踪 | pending → in_progress → resolved |
| 照片上传 | 支持上传问题照片 |

### 7. 数据看板

| 功能 | 描述 |
|------|------|
| 出租率统计 | 实时出租率计算 |
| 收租率统计 | 已收/应收比例 |
| 月收入趋势 | 折线图展示收入变化 |
| 房源分布 | 按房型/小区分布饼图 |
| 意向转化 | 意向→租约转化漏斗 |
| 报修概览 | 未处理/处理中/已解决统计 |

### 8. 通知系统

| 功能 | 描述 |
|------|------|
| 系统通知 | 平台公告、更新通知 |
| 中介状态 | 注册审核结果通知 |
| 支付提醒 | 账单到期提醒 |
| 收件箱 | 统一消息管理 |

---

## 技术特性

| 特性 | 说明 |
|------|------|
| 中英双语 | 完整i18n支持，运行时切换 |
| 深色/浅色主题 | 用户可自由切换 |
| 响应式设计 | 支持手机、平板、电脑 |
| 实时更新 | Supabase Realtime |
| 图片压缩 | 上传前自动压缩 |
| 匿名上传 | 扫码即传，无需登录 |
| Mock模式 | 无API时本地模拟运行 |

| admin_users | 管理员/中介 |

| unit_images | 房源媒体资源 |
| leases | 租约 |
| lease_groups | 合租组 |
| payment_records | 月账单 |
| lease_transfers | 租约转移 |
| tenant_interests | 合租意向 |
| maintenance_requests | 报修工单 |
| agent_registrations | 中介注册申请 |
| agent_conversations | AI对话历史 |
| universities | 马来西亚大学 |
| user_notifications | 系统通知 |
