# 小区知识库数据需求文档

## 目标

为 Malaysia Ez Rent 平台创建**马来西亚全境**的小区/公寓知识库，覆盖所有大学附近的住宅区域，用于 AI 智能推荐系统。

## 数据用途

1. AI 搜索增强：即使系统内没有房源，也能为用户提供小区信息
2. 房源推荐：根据用户需求匹配合适的小区
3. 租房指南：为新用户提供区域生活指南

---

## 采集范围

**不限定区域**，以大学为中心，搜索周边住宅：

```
马来西亚所有大学
    ↓
每所大学周边 3-5 公里范围
    ↓
所有住宅小区/公寓
```

## 采集流程

```
1. 获取马来西亚大学完整列表
   ↓
2. 逐一搜索每所大学周边住宅
   ↓
3. 提取小区信息
   ↓
4. 按格式输出 JSON
```

### 搜索关键词示例

```
"apartments near Sunway University"
"student housing Subang Jaya"
"condominiums for rent near Monash Malaysia"
"residential areas near University of Malaya"
```

## 数量目标

| 类别 | 目标数量 |
|------|---------|
| 大学 | 30+ 所 |
| 小区 | 每所大学 5-15 个 |
| **总计** | **200-400 个小区** |

---

## 数据质量要求

| 要求 | 说明 |
|------|------|
| **准确性** | 地址、坐标、租金要准确 |
| **客观性** | 优缺点要客观，不夸大 |
| **完整性** | 核心字段必须填写 |
| **时效性** | 租金范围要反映当前市场 |
| **无竞品链接** | 不要包含 iProperty、PropertyGuru 等网站链接 |
