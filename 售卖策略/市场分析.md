## 发展策略

### 第一阶段：验证期（0-6个月）

**目标**：验证PMF（Product-Market Fit）

| 行动 | 指标 |
|------|------|
| 获取100个中介 | 注册数 |
| 获取1000个租客 | 活跃用户 |
| 月成交50单 | 交易量 |
| NPS > 40 | 用户满意度 |

**策略**：
- 免费使用
- 线下推广（校园、中介公司）
- 口碑传播

### 第二阶段：增长期（6-18个月）

**目标**：规模化增长

| 行动 | 指标 |
|------|------|
| 付费中介50+ | MRR RM 10,000+ |
| 月成交200+单 | 交易量 |
| 覆盖5个城市 | 地理扩展 |

**策略**：
- 推出付费套餐
- 中介转介绍奖励
- 校园大使计划
- SEO/SEM投放

### 第三阶段：盈利期（18个月+）

**目标**：可持续盈利

| 行动 | 指标 |
|------|------|
| 付费中介150+ | MRR RM 30,000+ |
| 月成交500+单 | 交易量 |
| 毛利率 > 60% | 财务健康 |

**策略**：
- 多元化收入（佣金+订阅+广告）
- 扩展服务（搬家、清洁、保险）
- 融资扩张
- 国际化（新加坡、泰国）
