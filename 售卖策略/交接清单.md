### 需要买家自行配置

| 变量 | 说明 |
|------|------|
| SUPABASE_URL | 买家自己的Supabase项目 |
| SUPABASE_ANON_KEY | 买家自己的Key |
| SUPABASE_SERVICE_ROLE_KEY | 买家自己的Key |
| GEMINI_API_KEY | 买家自己的AI Key |
| GOOGLE_MAPS_API_KEY | 买家自己的Maps Key |

### 卖家需要撤走

| 服务 | 操作 |
|------|------|
| Supabase | 删除项目或移除买家访问权限 |
| Vercel | 删除项目或转移所有权 |
| Render | 删除服务或转移所有权 |
| Google Maps | 撤销API Key |

### 函数和触发器

| 名称 | 用途 |
|------|------|
| generate_lease_payments() | 自动生成月账单 |
| submit_tenant_interest() | 提交租房意向 |
| cancel_tenant_interest() | 取消租房意向 |
| substitute_co_tenant() | 替换合租租客 |

| match_units() | 语义搜索匹配 |

| trigger_clear_unit_number | 租约结束清理触发器 |

所有表均已启用 Row Level Security，策略文件在 `schema.sql` 中。

## 已知问题

1. **Windows部署**：前端必须使用 `--webpack` 参数（SWC不可用）
2. **数据库触发器**：需要运行033迁移添加支付生成触发器
3. **Room Type约束**：需要更新CHECK约束添加Ensuite房型
4. **图片压缩**：部分旧浏览器不支持Canvas压缩

2. 性能测试
3. 安全测试
