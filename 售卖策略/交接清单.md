## Git 仓库清理

### 方案一：创建干净分支（推荐）

```bash
# 1. 创建新的干净分支
git checkout -b v1.0-release

# 2. 删除不需要的文件
git rm -r --cached .claude/
git rm -r --cached .next/
git rm --cached *.png
git rm --cached frankfurterAPI

# 3. 更新 .gitignore
echo -e "\n# Sensitive files\n.claude/\n.next/\n*.png\n*.jpg\n*.jpeg\nfrankfurterAPI" >> .gitignore

# 4. 提交
git add .
git commit -m "chore: clean up for handover"

# 5. 推送
git push origin v1.0-release
```

### 方案二：新建仓库（最干净）

```bash
# 1. 在 GitHub 创建新仓库

# 2. 只复制必要文件
mkdir ezrent-clean
cp -r frontend/ ezrent-clean/
cp -r backend/ ezrent-clean/
cp -r supabase/ ezrent-clean/
cp -r 售卖策略/ ezrent-clean/
cp .gitignore ezrent-clean/
cp README.md ezrent-clean/
cp PROGRESS.md ezrent-clean/

# 3. 初始化并推送
cd ezrent-clean
git init
git add .
git commit -m "initial commit"
git remote add origin <new-repo-url>
git push -u origin main
```

### 方案三：重写历史（删除敏感记录）

使用 BFG Repo Cleaner：

```bash
# 1. 克隆裸仓库
git clone --mirror https://github.com/xxx/repo.git

# 2. 下载 BFG
# https://rtyley.github.io/bfg-repo-cleaner/

# 3. 删除敏感文件
java -jar bfg.jar --delete-files ".claude/*" repo.git
java -jar bfg.jar --delete-files ".next/*" repo.git
java -jar bfg.jar --delete-files "*.png" repo.git

# 4. 清理并推送
cd repo.git
git reflog expire --expire=now --all
git gc --prune=now --aggressive
git push --force
```
