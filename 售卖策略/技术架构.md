# 技术架构

## 技术栈总览

```
┌─────────────────────────────────────────────────────┐
│                    前端 (Vercel)                     │
│  Next.js 16 + React 19 + TypeScript + Tailwind CSS  │
└─────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────┐
│                    后端 (Render)                     │
│            Python FastAPI + SSE 流式响应             │
└─────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────┐
│                 Supabase (云端)                      │
│  PostgreSQL + pgvector + Auth + Storage + Realtime  │
└─────────────────────────────────────────────────────┘
```

## 部署架构

### Vercel（前端）

```
GitHub 仓库
    │
    ├── git push
    │
    ▼
Vercel 自动构建
    │
    ├── Build: next build
    │
    ▼
全球 CDN 部署
    │
    └── https://ezrent.my
```

```
GitHub 仓库
    │
    ├── git push
    │
    ▼
Render 自动构建
    │

    ▼
```

## 安全设计

| 机制 | 说明 |
|------|------|
| Supabase RLS | 所有表启用行级安全 |
| JWT认证 | 后端验证Bearer Token |
| Service Role隔离 | 高权限Key仅后端使用 |
| 数据隔离 | 中介只能访问自己的数据 |
| 匿名上传 | 手机端无需登录 |
| InAppBrowser检测 | 防止内嵌浏览器问题 |
