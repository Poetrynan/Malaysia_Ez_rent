# Malaysia Ez Rent - 售卖策略与商业文档

## 项目简介

马来西亚智能租房平台，面向所有国际租客（留学生、外派员工、外籍人士等）提供一站式租房服务，集成 AI 助手、全流程租约管理、手机扫码缴租、多中介独立挂牌等功能。

## 已完成功能

| 功能 | 状态 | 说明 |
|------|------|------|
| AI 智能助手 | ✅ | 通勤测算、汇率换算、语义搜索 |
| 多中介独立挂牌 | ✅ | 数据隔离，独立管理 |
| 租约全流程管理 | ✅ | 创建、审核、终止、归档 |
| 支付跟踪 | ✅ | 扫码缴租、付款审核 |
| 报修系统 | ✅ | 工单提交、对话沟通 |
| 数据看板 | ✅ | 出租率、收租率、趋势图 |
| 收藏夹 | ✅ | 租客收藏房源 |
| 租客评价 | ✅ | 星级评分 + 资格限制 |
| 可入住日期 | ✅ | 房源可用时间 |
| 中英双语 | ✅ | 运行时切换 |
| 深色/浅色主题 | ✅ | 用户可切换 |
